# Компьютерная графика

Лабораторные работы по курсу «Компьютерная графика» в МАИ. Вариант 7 — тор. Работы написаны на C++20 с использованием Vulkan, GLFW и ImGui.

## Лабораторные работы

В README каждой работы описаны её особенности, запуск и управление. Там же собраны ссылки на материалы.

| Работа | Что реализовано |
| --- | --- |
| [№ 1. Основы 3D-графики](lab1/README.md) | Построение тора, перспективная и ортографическая проекции, преобразования и анимация. [Папка с кодом и отчётом для сдачи](https://github.com/Girday/CG/tree/main/lab1). |
| [№ 2. Камера и освещение](lab2/README.md) | Камера и освещение по модели Блинна–Фонга: направленный свет, точечные источники и прожекторы. |
| [№ 3. Текстурирование](lab3/README.md) | Текстуры с анимацией координат, карты бликов и свечения, динамические буферы параметров объектов. |
| [№ 4. Тени](lab4/README.md) | Карты теней от направленного источника и выбранного прожектора с использованием Vulkan Dynamic Rendering. |

## Сборка и запуск

Нужны CMake 3.20 или новее, компилятор с поддержкой C++20 и Vulkan SDK с `glslc` в `PATH`. На macOS Vulkan работает через MoltenVK. Для запуска работы № 4 нужна поддержка Vulkan 1.3 и функции `dynamicRendering`.

### Быстрый запуск на macOS

Из корня репозитория выполните команду для нужной работы:

```sh
./lab2/run-macos.sh
./lab3/run-macos.sh
./lab4/run-macos.sh
```

Каждый скрипт собирает и запускает свою работу. По умолчанию скрипты ищут SDK в `~/VulkanSDK/1.4.321.0`. Если SDK установлен в другом месте, задайте `CG_VULKAN_SDK_ROOT`. Для работы № 1 используйте ручную сборку ниже.

### Ручная сборка

После настройки Vulkan SDK (на macOS подключите `setup-env.sh` из каталога SDK) выполните из корня репозитория:

```sh
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug --parallel
ctest --test-dir build-debug --output-on-failure
```

Чтобы собрать одну работу, добавьте `--target cg-labN` к команде сборки, где `N` — номер работы.

В macOS и Linux работы № 2–4 можно запустить из корня репозитория, подставив нужный номер в `./build-debug/labN/cg-labN`. Работу № 1 запускайте из каталога `lab1`, чтобы приложение нашло шейдеры:

```sh
(cd lab1 && ../build-debug/lab1/cg-lab1)
```

Для Visual Studio используйте пресет `msvc-debug` и укажите конфигурацию `Debug` при сборке (`--config Debug`) и запуске тестов (`-C Debug`). Исполняемые файлы находятся в подкаталогах `build-debug/labN/Debug/`.
