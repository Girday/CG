Оригинальные бесшовные текстуры для этой сцены, 512×256 RGB PNG:

- `porcelain.png`: синие узоры на светлой плитке; specular-карта выделяет золотые швы.
- `circuit.png`: дорожки печатной платы; отдельные specular и emissive карты.
- `woven.png`: матовая ткань без дополнительных карт.
- `black.png`: один чёрный пиксель, подставляется вместо отсутствующих карт.

Изображения сохранены на диске и декодируются `stb_image` при запуске.
Восстановление файлов: `python3 lab3/tools/generate_textures.py` из корня репозитория.
Для своих PNG можно заменить файлы с теми же именами или задать каталог
через `CG_TEXTURE_DIR`. Цветовые albedo/emissive карты загружаются как sRGB,
specular-карты — как линейные маски.
